# Task2 Blog API

A blog application API built with Node.js, Express, and MongoDB. Users can register, create posts, and add comments.

## Features
- User registration with password hashing
- Post creation, retrieval, update, and deletion
- Comment creation, retrieval, and deletion
- Relationship population using Mongoose
- Cascade deletion of comments when a post is deleted

## Run
1. `npm install`
2. Create a `.env` file with `MONGODB_URI`
3. `npm run dev`
